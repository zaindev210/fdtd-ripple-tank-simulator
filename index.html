Waves & Physical Optics — Core Formulas

Key algebraic wave relations demonstrated in this ripple tank lab (Ch. 7 & Ch. 8 — Waves and Physical Optics):

1. Fundamental Wave Equation v = f λ   (T = 1 / f)
2. Constructive Interference (Antinodes) ΔS = mλ   (m = 0, 1, 2, …)
3. Destructive Interference (Nodes) ΔS = (m + ½)λ   (m = 0, 1, 2, …)
4. Young's Double-Slit Fringe Spacing Δy = λL / d
5. Doppler Effect (Moving Source) f′ = [ v / (v ∓ vₛ) ] · f
Computational Engine: 2D FDTD Solver (Technical Notes) ▼

Rather than pre-computed sine overlays, the simulation solves the 2D scalar wave equation (∂²u/∂t² = v²∇²u) in real time across a 384 × 256 grid using an explicit leapfrog Finite-Difference Time-Domain (FDTD) stencil:

// 2D FDTD Leapfrog Stencil
u[i,j]ⁿ⁺¹ = 2u[i,j]ⁿ − u[i,j]ⁿ⁻¹ + C²(u[i+1,j]ⁿ + u[i−1,j]ⁿ + u[i,j+1]ⁿ + u[i,j−1]ⁿ − 4u[i,j]ⁿ)
// CFL Stability Condition & Mur Absorbing Boundary
C = v · Δt / Δx ≤ 1 / √2 ≈ 0.707  |  u[0,j]ⁿ⁺¹ = u[1,j]ⁿ + ((C−1)/(C+1))(u[1,j]ⁿ⁺¹ − u[0,j]ⁿ)
